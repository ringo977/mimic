OPZIONE A - VELOCE (Raccomandato) ⚡ 10 minuti
───────────────────────────────────────────────
1. mkdir organ-on-chip-polimi && cd organ-on-chip-polimi
2. cursor .
3. Apri Composer (Cmd/Ctrl + I)
4. Copia TUTTO il contenuto di CURSOR_PROMPT.md
5. Incolla nel Composer
6. Aspetta generazione (2-3 min)
7. npm install && npm run dev
8. Apri http://localhost:3000
✅ FUNZIONA!

OPZIONE B - MANUALE 🔧 2-4 ore
───────────────────────────────
Segui il README.md step-by-step per setup manuale completo

OPZIONE C - IBRIDA 🔀 1-2 ore
──────────────────────────────
Usa Cursor per struttura base + personalizza con componenti forniti
